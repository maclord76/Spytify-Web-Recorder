# Politique de sécurité

## Versions prises en charge

Seule la version présente sur la branche principale est maintenue. La version actuelle déclarée par l'extension est **1.18.5**.

## Signaler une vulnérabilité

N'ouvrez pas d'issue publique pour une vulnérabilité susceptible d'exposer un compte Spotify, un jeton, des données personnelles, un fichier local ou une capture audio. Utilisez la fonction de signalement privé de sécurité du dépôt GitHub lorsqu'elle est activée. Si elle n'est pas disponible, contactez le mainteneur via son profil GitHub et demandez un canal privé.

Incluez une description claire, les versions concernées, les prérequis, les étapes de reproduction sans données sensibles, l'impact potentiel et, si vous en avez une, une proposition de correction. Un accusé de réception sera envoyé dès que possible ; ne rendez pas le problème public avant accord du mainteneur.

## Portée

Sont notamment concernés les permissions Chrome, la capture d'onglet, l'attachement temporaire du débogueur, les téléchargements et toute fuite de données ou élévation de privilèges. Les demandes d'assistance générale ne sont pas des vulnérabilités et doivent être ouvertes comme issues ordinaires.
